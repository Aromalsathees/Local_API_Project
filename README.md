# 🗺️ Map-Based Travel Recommendation System

A web-based application that provides users with travel recommendations and details of various destinations using an interactive map interface.

## 📌 Features

- 📍 Interactive map-based UI for exploring destinations  
- 🧭 Local JSON API for fast data loading without external dependencies  
- 🎨 Clean, responsive design with Tailwind CSS  
- 🧰 Backend built using Django (Python)  
- 🌐 Frontend built using HTML + JavaScript  
- 🔍 Search and filter destinations by name, state, or category  
- 📷 Multiple images for each destination  
- 🔗 Google Map redirection for live location view
